# 🐍 python-office Project Overview

> **One line of code for office automation** — A one-stop Python library for office automation

## What is it?

**python-office** is a **Python library for office automation scenarios**, developed and maintained by "CoderWanFeng" (程序员晚枫).

It encapsulates common office automation operations (Excel processing, Word conversion, PDF operations, email sending, WeChat bots, etc.) into **simple Python APIs**, allowing you to complete complex tasks with **just one line of code** that would otherwise require dozens of lines.

## Core Philosophy

> **Make Python office automation as simple as Excel formulas**

## Three Key Advantages

| Advantage | Description |
|-----------|-------------|
| 🚀 **One Line of Code** | No complex parameters to remember, ready to use |
| 📚 **Complete Documentation** | Every function has detailed parameter descriptions and examples |
| 🛡️ **Actively Maintained** | Active open-source community, regular updates |

## 13 Core Modules

| Module | Description |
|--------|-------------|
| 📊 **Excel** | Data generation, merge, split, search, PDF export |
| 📝 **Word** | Word/PDF conversion, merge, image extraction |
| 📑 **PDF** | Conversion, encryption, merge, split, watermark |
| 📊 **PPT** | Convert to PDF, convert to images (long image), merge |
| 🖼️ **Image** | Compression, watermark, QR code, word cloud, cartoonify |
| 📁 **File** | Batch rename, file search, organization |
| 📧 **Email** | Auto-send (with attachments, CC, mass), receive |
| 💬 **WeChat** | Send messages, schedule, keyword reply, mass send, chat |
| 🔍 **OCR** | VAT invoice recognition → Excel |
| 🎬 **Video** | Audio/video conversion, watermark, text-to-speech |
| 📝 **Markdown** | Excel to Markdown |
| 💰 **Finance** | Stock T+0 profit calculation |
| 🛠️ **Tools** | Translation, QR code, password, weather and 10+ other tools |
