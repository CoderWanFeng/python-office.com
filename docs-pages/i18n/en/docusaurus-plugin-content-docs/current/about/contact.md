## Issue Reporting Workflow

1. **Check the docs first**: visit [FAQ](/start/faq) and [Module Documentation](/modules/overview)
2. **Search issues**: search [GitHub Issues](https://github.com/CoderWanFeng/python-office/issues)
3. **Submit an issue**: if none matches, file a new issue
4. **Join the chat group**: for urgent questions, ask in the WeChat group
