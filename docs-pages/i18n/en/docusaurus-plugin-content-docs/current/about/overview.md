# ℹ️ About python-office

## Project Introduction

**python-office** is a **one-stop Python library for office automation**, developed and maintained by "CoderWanFeng" (程序员晚枫).

The core philosophy: **make Python office automation as simple as Excel formulas**.

By encapsulating common operations for various office scenarios (Excel, Word, PDF, email, WeChat, etc.), it lets you complete complex tasks that would otherwise require dozens of lines of code with **just one line of code**.

## Highlights

- 🧩 **13 modules**: covers every aspect of office automation
- 🚀 **72+ APIs**: complex operations in one line of code
- 📚 **Complete documentation**: detailed parameters and examples for every function
- 🛡️ **Actively maintained**: an active open-source community with regular updates
- 🌐 **Bilingual**: suitable for both Chinese and international users
