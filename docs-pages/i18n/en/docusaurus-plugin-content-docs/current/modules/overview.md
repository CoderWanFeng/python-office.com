## How to choose a module?

- Want to process **Excel spreadsheets** → [Excel module](/modules/excel/guide)
- Want to convert **document formats** (PDF ↔ Word ↔ PPT) → [PDF module](/modules/pdf/guide)
- Want to add **watermarks to images / generate QR codes** → [Image module](/modules/image/guide)
- Want to build a **WeChat bot** → [WeChat module](/modules/wechat/guide)
- Want to **send emails automatically** → [Email module](/modules/email/guide)
- Want to **manage files in bulk** → [File module](/modules/file/guide)

## Learning Tips

1. **Learn on demand**: You don't have to learn every module at once — pick what you need.
2. **Start with the guide**: Each module's `guide.md` contains multiple real-world examples.
3. **Skip the guide for API lookup**: Reading `api.md` directly is faster.
