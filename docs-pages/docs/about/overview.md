# 关于 python-office

## 项目简介

**python-office** 是一个**一站式的 Python 自动化办公库**，由作者「程序员晚枫」开发并维护。

项目的核心理念是：**让 Python 自动化办公像 Excel 公式一样简单**。

通过封装各种办公场景的常用操作（Excel、Word、PDF、邮件、微信等），让用户能够通过**一行代码**完成原本需要数十行代码的复杂任务。

## 项目特点

- 🧩 **13 大模块**：覆盖办公自动化的方方面面
- 🚀 **72+ 个 API**：一行代码搞定复杂操作
- 📚 **完整文档**：每个函数都有详细参数和示例
- 🛡️ **持续维护**：活跃的开源社区，定期更新
- 🌐 **中英双语**：适合国内外用户使用
