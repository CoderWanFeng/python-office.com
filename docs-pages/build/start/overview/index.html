🐍 python-office 项目概览

一行代码搞定自动化办公 — Python 自动化办公一站式库

是什么？​

python-office 是一个面向办公自动化场景的 Python 库，由「程序员晚枫」开发并维护。

它将常用的办公自动化操作（Excel 处理、Word 转换、PDF 操作、邮件发送、微信机器人等）封装为简单的 Python API，让你能通过一行代码完成原本需要数十行代码的复杂任务。

核心理念​

让 Python 自动化办公像 Excel 公式一样简单

三大优势​

优势说明
🚀 一行代码无需记忆复杂参数，开箱即用
📚 完整文档每个函数都有详细参数说明和示例
🛡️ 持续维护活跃的开源社区，定期更新

模块简介
📊 Excel数据生成、合并、拆分、搜索、PDF 导出
📝 WordWord/PDF 转换、合并、图片提取
📑 PDF转换、加解密、合并、拆分、水印
📊 PPT转 PDF、转图片（支持长图）、合并
🖼️ Image压缩、水印、二维码、词云、卡通化
📁 File批量重命名、文件搜索、整理
📧 Email自动发送（带附件、抄送、群发）、接收
