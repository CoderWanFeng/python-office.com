📊 Python Office - 办公自动化 API

为 AI Agents 提供的 Python 办公自动化技能接口

📡 API 端点

GET /api/automations - 获取自动化技能列表
GET /api/automations/ai-friendly - AI 友好格式
GET /api/automations/:id - 获取详情
GET /api/categories - 获取分类

🤖 MCP Tools

POST /api/mcp - 调用 MCP 工具 
curl -X POST http://localhost:3004/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"name":"search_automations","arguments":{"query":"Excel"}}'

  • PDF处理
  • 邮件自动化
  • 网页爬虫
  • 图片处理
  • Word自动化

npm run dev - 启动服务 (http://localhost:3004)
