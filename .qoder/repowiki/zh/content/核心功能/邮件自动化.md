## SMTP/IMAP配置与认证

### 配置方法
邮件自动化功能基于SMTP协议发送邮件和IMAP协议接收邮件，需要配置相应的授权码和邮箱地址。

#### 环境变量配置
推荐使用环境变量存储敏感信息，如授权码、邮箱地址等。

```python
key = os.getenv('EMAIL_KEY')  # 从环境变量获取授权码
msg_from = "your_email@domain.com"  # 发件人邮箱
```

#### 直接配置
也可以直接在代码中配置，但不推荐用于生产环境。

### 认证流程
1. 获取邮箱授权码（非登录密码）
2. 配置SMTP/IMAP服务器信息
3. 建立安全连接（SSL/TLS）
4. 身份验证
5. 执行邮件操作

## 常见问题处理

### 被识别为垃圾邮件
- **问题原因**：邮件内容、发送频率、发件人信誉等因素可能导致邮件被识别为垃圾邮件
- **解决方案**：
  - 使用正规邮箱服务提供商
  - 避免使用敏感词汇
  - 逐步增加发送量，建立发件人信誉
  - 添加邮件认证（SPF、DKIM、DMARC）

### 附件大小限制
- **问题原因**：不同邮箱服务商对附件大小有限制
- **解决方案**：
  - 压缩大文件
  - 使用云存储链接代替大附件
  - 分割大文件为多个小文件发送
  - 检查目标邮箱的附件大小限制

### 连接超时
- **问题原因**：网络问题或服务器限制
- **解决方案**：
  - 添加重试机制
  - 调整超时设置
  - 避开高峰期发送

## Excel数据结合批量邮件通知案例

### 完整实现流程
结合Excel数据实现批量邮件通知的完整案例，适用于学生通知、员工通知等场景。

```mermaid
flowchart TD
Start([开始]) --> ReadExcelData["读取Excel数据文件"]
ReadExcelData --> ExtractEmails["提取收件人邮箱列表"]
ExtractEmails --> LoopEmails["循环处理每个邮箱"]
LoopEmails --> PersonalizeContent["个性化邮件内容<br/>替换模板变量"]
PersonalizeContent --> AddAttachments["添加通用附件"]
AddAttachments --> SendEmail["发送个性化邮件"]
SendEmail --> LogResult["记录发送结果"]
LogResult --> NextEmail["处理下一个邮箱"]
NextEmail --> CheckAllDone["所有邮箱处理完毕？"]
CheckAllDone --> |否| LoopEmails
CheckAllDone --> |是| GenerateReport["生成发送报告"]
GenerateReport --> End([批量通知完成])
```

### 实现步骤
1. 准备Excel文件，包含收件人邮箱和其他个性化信息
2. 读取Excel文件数据
3. 遍历数据行，为每个收件人生成个性化邮件
4. 发送邮件并记录结果
5. 生成发送报告
